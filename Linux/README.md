# NixOS Configuration

NixOS configuration with Hyprland window manager based on [caelestia-dots](https://github.com/caelestia-dots) and [meowrch](https://github.com/meowrch).

**Interactive Installer**
This configuration comes with an interactive, fully automated installation script. You no longer need to manually copy files or copy hardware configs manually.
Simply run the script from the `Linux/` root directory:

```bash
./install.sh
```

The script will prompt you for your username, password, timezone, locale, GPU drivers, Secure Boot preference, regional restrictions (e.g. DPI bypass via Zapret), configure and apply the new system state automatically.

## Configuration Structure

```text
Linux/NixOS/
├── flake.nix                     # Flake inputs + nixosConfigurations.<host>
├── hosts/
│   └── NixOS/
│       ├── default.nix           # Host entry point - imports all modules
│       ├── variables.nix         # Single source of truth (config.var.*)
│       ├── hashed-password.nix   # Generated by installer (root:600)
│       └── secrets/sops.nix      # System-level sops-nix skeleton
│
├── system/                       # Core system config (boot, locale, network)
├── services/                     # Services (Zapret, OmniRouter, Databases)
├── programs/                     # NixOS-level config (Fish, Thunar, Hyprland)
├── packages/                     # Packages (system, tools, fonts)
├── users/                        # User definitions
├── home/                         # Home Manager (programs, themes, apps)
│   ├── home.nix                  # HM entry point
│   ├── programs/                 # Per-app HM configuration
│   └── secrets/default.nix       # HM-level sops-nix skeleton
├── themes/                       # Visual themes (GRUB, Plymouth, SDDM)
└── Wallpapers/                   # Image assets
```

## Key Configuration Features

> **Note:** The `./install.sh` script automatically configures most of these based on your prompts. However, if you prefer to edit definitions manually later, here is what goes under the hood and where.

### Bootloader Selection (GRUB vs Secure Boot)

**Configuration Location**: `system/boot/`

By default, the system uses GRUB.
If you migrate to **Secure Boot (Lanzaboote)**, you must:

1. Clear Secure Boot keys in BIOS & setup mode.
2. Edit `hosts/NixOS/default.nix`:
   - Uncomment `../../system/boot/secure.nix`
   - Comment out `../../system/boot/plymouth.nix` _(Plymouth hooks into the early boot stage and interferes with Lanzaboote's signed initrd, causing a black screen)_.
3. Enroll keys (One-time):
   ```bash
   sudo sbctl create-keys
   sudo sbctl enroll-keys --microsoft
   ```

### DPI Circumvention (Zapret)

**Configuration Location**: `services/zapret.nix`

Includes a pre-configured service based on [Kartavkun Zapret](https://github.com/kartavkun/zapret-discord-youtube) to bypass DPI censorship (Discord Voice, YouTube).

- Configured via multiple strategy options (e.g. `FAKE_TLS_AUTO_ALT`) selectable right from the installer.
- Works smoothly with MGTS / GPON providers.

### Custom Local Services (OmniRouter)

**Configuration Location**: `services/system-services.nix` and `modules/omnirouter.nix`

- **OmniRouter**: A custom Local LLM router running on `localhost:20128` as a system service. Can be enabled/disabled during installation.

### Security, Tooling & Databases (Commented out by default)

- **CTF Tools**: Comprehensive set of security tools from `nixpkgs-stable`. Uncomment `../../packages/ctf` in `hosts/NixOS/default.nix` to enable (or pick the option in the installer).
- **Observability Stack**: Grafana (`3010`), Prometheus (`9100`), Loki (`3110`). Disabled by default. Rename `services/observability.nix.example` to `services/observability.nix` and add the import in `hosts/NixOS/default.nix` to activate.
- **Database Custom Ports**:
  - PostgreSQL 17 explicitly exposed on `5442`. **After install, immediately change the password**:
    ```bash
    sudo -u postgres psql -p 5442
    ALTER USER postgres WITH PASSWORD 'new_password'; \q
    ```
  - Optional Redis (`6389`) and ClickHouse (`8133`, `9010`) are defined but commented out in `services/databases.nix`.

### Zen Browser + Sine Mod Manager

**Configuration Location**: `packages/zen-browser.nix`

Zen Browser is installed with [Sine](https://github.com/CosmoCreeper/Sine) - a community-driven mod and theme manager - pre-patched via a NixOS-native overlay.

#### How it works

Installation is split into two parts:

| Part           | What                                          | How                                                                           |
| -------------- | --------------------------------------------- | ----------------------------------------------------------------------------- |
| **Bootloader** | `config.js` + `defaults/pref/config-prefs.js` | Baked into the browser via `packages/zen-browser.nix` at `nixos-rebuild` time |
| **Profile**    | `profile.zip` + `engine.zip` + `locales.zip`  | Downloaded and extracted into `~/.zen/*/chrome/` by `install.fish`            |

#### Steps

1. **Rebuild the system** to apply the bootloader patch:

   ```bash
   sudo nixos-rebuild switch --flake /etc/nixos#NixOS
   ```

2. **Run the dotfiles installer** (from the repo, not from `/etc/nixos/`) to set up the profile part and the Catppuccin Macchiato theme:

   ```bash
   fish <repo>/Linux/dots/install.fish
   ```

3. **Open Zen Browser** and go to `about:config`, enable:

   ```
   toolkit.legacyUserProfileCustomizations.stylesheets = true
   ```

4. **Restart Zen Browser** - Sine will appear inside the browser's Settings page.

> After Sine is running, you can install additional mods directly from its built-in marketplace.

### Power Management (Battery Optimization)

**Configuration Location**: `system/power.nix`

Uses `auto-cpufreq` for dynamic CPU frequency scaling based on load and power source:

- **On battery**: `powersave` governor, turbo boost disabled, max freq capped at 1.8GHz
- **On charger**: `performance` governor, turbo boost auto

`power-profiles-daemon` is explicitly disabled - it conflicts with `auto-cpufreq` over CPU governor control.

`powertop --auto-tune` runs on boot to enable runtime power management for all PCI/USB devices.

To check current status:

```bash
auto-cpufreq --stats
```

### Regional Restrictions (Russian Federation)

**Configuration Location**: `home/apps.nix`

JetBrains IDEs (GoLand, DataGrip) enforce geo-blocking download restrictions. The installer automatically detects if you're in Russia and comments out these packages so your build doesn't break. To fetch them manually via proxies, you can uncomment them later.

## Manual Installation (Advanced)

If you completely skip `./install.sh`:

1. Base Partitioning:
   ```bash
   mkfs.fat -F 32 /dev/sda1
   mkfs.ext4 /dev/sda2
   mount /dev/sda2 /mnt
   mkdir -p /mnt/boot
   mount /dev/sda1 /mnt/boot
   sudo nixos-generate-config --root /mnt
   ```
2. Clone repo into `/mnt/etc/nixos/`, set `config.var.username` etc. in `hosts/NixOS/variables.nix`, and create `hosts/NixOS/hashed-password.nix` with `initialHashedPassword` (use `mkpasswd -sm sha-512 --rounds=656000`).
3. Install:
   ```bash
   sudo nixos-install --flake .#NixOS
   ```
4. Post-Install user dotfiles (Hyprland scripts, Zen Browser theme, Sine, Neovim):
   ```bash
   fish <repo>/Linux/dots/install.fish
   ```

## Maintenance

### Updating the System

Use the pre-made Fish alias:

```fish
update
```

Which expands to: `cd /etc/nixos && nix flake update && nixos-rebuild switch --flake .#NixOS`

### Garbage Collection

Runs automatically daily. To forcefully clean manual storage:

```bash
sudo nix-collect-garbage -d
sudo nixos-rebuild boot --flake /etc/nixos#NixOS
```
